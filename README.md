# 🏢 سامانه جامع مدیریت و معاملات املاک (Real Estate Management System)

این پروژه یک سامانه کنسولی مدیریت و معاملات ملکی است که به زبان **Java 8** توسعه داده شده است. معماری پروژه بر اساس اصول شی‌گرایی کلاسیک، الگوهای طراحی استاندارد (مانند Factory Pattern)، اصول **SOLID** و **Clean Code** طراحی شده و **بدون وابستگی به ساختارهای پیچیده نظیر Lambda Expressions، Streams API یا ویژگی‌های جاوا ۹+** پیاده‌سازی گردیده است.

- **Java Development Kit (JDK) 8 یا بالاتر** (کامپایلر با هدف جاوا ۸ پیکربندی شده است).

### ۱. اجرای برنامه اصلی (Application)
- **در سیستم‌عامل مک (macOS):**
  می‌توانید مستقیماً روی فایل [`run.command`](file:///Users/amin/Desktop/realestate/run.command) یا [`run_app.command`](file:///Users/amin/Desktop/realestate/run_app.command) در Finder **دابل کلیک** کنید تا ترمینال باز شده و برنامه بلافاصله اجرا گردد.
- **در محیط خط فرمان (ترمینال):**
```bash

# یا
./run_app.command
```
یا با دستورات استاندارد زیر در ترمینال اجرا نمایید:
```bash

javac --release 8 -d bin $(find src -name "*.java")
java -cp bin Main
```

## ✨ قابلیت‌ها و ویژگی‌های کلیدی سامانه

1. **احراز هویت و امنیت حساب کاربری:**
   - ثبت‌نام با تکرار کلمه عبور و اعتبارسنجی ورودی‌های غیرخالی.
   - هش‌گذاری یک‌طرفه با الگوریتم SHA-256 و تعیین صریح انکودینگ `StandardCharsets.UTF_8`.
   - عدم حساسیت نام کاربری به حروف بزرگ/کوچک (Case-Insensitive).

2. **مدیریت و ثبت املاک (الگوی Factory):**
   - پشتیبانی از ۳ نوع ملک: **آپارتمان**، **ویلا** و **پنت‌هاوس**.
   - دسته‌بندی وضعیت معامله: برای فروش (`FOR_SALE`)، برای اجاره (`FOR_RENT`)، هر دو (`BOTH`) و ثبت‌نشده (`NOT_LISTED`).

3. **معاملات ملکی پیشرفته:**
   - **خرید عادی ملک:** انتقال مالکیت، پرداخت وجه به فروشنده و به‌روزرسانی آنی لیست خریدهای فروشنده و خریدار.
   - **اجاره ملک:** کسر اجاره ماهانه از مستأجر، واریز به مالک و صدور قرارداد اجاره.
   - **خرید ویژه (Special Purchase):** امکان خرید ملک با پرداخت ۲ برابر قیمت، تخلیه مستأجر و صدور قرارداد خرید ویژه.
   - **فروش فوری به بنگاه (Quick Sell):** فروش ملک با ۱۰٪ تخفیف به بنگاه املاک و تغییر وضعیت آن برای واگذاری به سایر کاربران.
   - **بازگذاری مجدد ملک (Relist):** امکان تغییر وضعیت ملک توسط مالک جدید پس از خرید.

4. **مدیریت قراردادها و لغو اجاره:**
   - نمایش لیست قراردادهای مرتبط با کاربر جاری (تشخیص هوشمند نام طرف مقابل).
   - امکان فسخ قرارداد اجاره توسط مستأجر با پرداخت جریمه ۱.۵ برابری به موجر و آزادسازی ملک برای اجاره مجدد.

5. **پایداری و یکپارچگی داده‌ها (Data Integrity):**
   - **ابطال خودکار قراردادهای شبح (Ghost Contracts):** هنگام خرید عادی، خرید ویژه یا فروش ملک به بنگاه، تمامی قراردادهای اجاره قبلی به‌صورت خودکار باطل می‌شوند تا مستأجر سابق نتواند قرارداد منقضی‌شده را دستکاری کند.
   - **جلوگیری از اجاره ملک به خود (`SELF_RENT_FORBIDDEN`).**
   - **شمارنده‌های ترتیبی (Monotonic Sequence Counters):** جلوگیری از تداخل شناسه‌ها (`USR-X`, `HSE-X`, `CTR-X`) حتی پس از حذف رکوردها.
   - **اعتبارسنجی سخت‌گیرانه ورودی‌ها:** جلوگیری از ورود مقادیر منفی در بودجه، متراژ، تعداد اتاق و محدوده نامعتبر مناطق شهری (تنها ۱ تا ۴ مجاز است).

## 📐 فرمول‌های محاسباتی

| آیتم | فرمول محاسبه |
| :--- | :--- |
| **قیمت پایه ملک** | $\text{BasePrice} = \text{Area} \times 10,000,000 \times \text{RegionCoefficient}$ |
| **ضرایب مناطق** | منطقه ۱: `1.8` \| منطقه ۲: `1.4` \| منطقه ۳: `1.1` \| منطقه ۴: `0.8` (پیش‌فرض: `1.0`) |
| **ضریب اتاق و طبقه** | $\text{Bonus} = (1 + 0.03 \times \text{Bedrooms}) \times (1 + 0.01 \times \text{Floor})$ |
| **قیمت نهایی آپارتمان** | $\text{Price} = \text{BasePrice} \times \text{Bonus}$ |
| **قیمت نهایی ویلا** | $\text{Price} = \text{BasePrice} + (\text{YardArea} \times 3,000,000) + (\text{FloorsCount} \times 15,000,000)$ |
| **قیمت نهایی پنت‌هاوس** | $\text{Price} = (\text{BasePrice} \times 1.5) + (\text{TerraceArea} \times 5,000,000)$ |
| **اجاره ماهانه** | $\text{Rent} = \text{Price} \times 0.004$ (۰.۴ درصد قیمت کل) |
| **جریمه فسخ اجاره** | $\text{Penalty} = \text{Rent} \times 1.5$ (۱.۵ برابر اجاره ماهانه) |
| **فروش فوری به بنگاه** | $\text{QuickSellPrice} = \text{Price} \times 0.9$ (۹۰ درصد قیمت کل) |
| **خرید ویژه** | $\text{SpecialPrice} = \text{Price} \times 2$ (۲ برابر قیمت کل) |
